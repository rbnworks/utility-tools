1. Update the scan command's background task to use compute_hashes_for_file():

   In the existing background task (from Plan 03-01), find the hash computation loop:
   ```rust
   // OLD (image-only):
   match hash::compute_hashes_for_path(&file.path) {
       Ok(file_hash) => { ... }
       Err(e) => { log::warn!(...); }
   }
   ```

   Replace with:
   ```rust
   // NEW (video-aware):
   match hash::compute_hashes_for_file(&file.path, &file.file_type) {
       Ok(file_hash) => {
           hash_cache.insert(file.path.clone(), (file_hash.clone(), file.size));
           all_hashes.push((file.clone(), file_hash));
       }
       Err(e) => {
           log::warn!("Failed to hash {}: {}", file.path, e);
       }
   }
   ```

2. Add abort signal wiring in the background task:

   After the file hash computation loop (before the grouping section), add an abort signal check:
   ```rust
   // Check for cancellation between files
   if abort_tx.try_send(()) {
       // Abort signal received — stop scanning
       log::info!("Scan cancelled by user");
       let _ = app.emit("scan:cancelled", session_id.clone());
       {
           let mut session = SESSIONS.get_mut(&session_id).unwrap();
           session.status = ScanStatus::Cancelled;
       }
       return;  // Exit background task early
   }
   ```

   NOTE: The `abort_tx` comes from SessionState (added in Plan 03-03). The background task needs to receive from the abort channel. Use:
   ```rust
   use tokio::select;
   
   // In the background task, for each file processed:
   select! {
       biased;  // Abort check takes priority
       _ = rx.recv() => { break; }  // Abort received
       _ = tokio::time::sleep(tokio::time::Duration::from_millis(100)) => {
           // Normal processing continues
       }
   }
   ```

   Actually, a simpler approach: store an `Arc<tokio::sync::atomic::AtomicBool>` in SessionState that the cancel_scan command sets to true. The background task checks it each iteration:
   ```rust
   // In SessionState (from Plan 03-03):
   pub abort_requested: std::sync::Arc<std::sync::atomic::AtomicBool>,
   
   // In the background task loop (check each file):
   let session = SESSIONS.get(&session_id).unwrap();
   if session.abort_requested.load(std::sync::atomic::Ordering::Relaxed) {
       log::info!("Scan cancelled");
       let _ = app.emit("scan:cancelled", session_id.clone());
       {
           let mut s = SESSIONS.get_mut(&session_id).unwrap();
           s.status = ScanStatus::Cancelled;
       }
       return;
   }
   ```
