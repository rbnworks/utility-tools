  <action>
Add video-specific hashing functions to hash.rs. This task adds three new functions:
1. compute_hashes_for_video() — extracts frames and hashes each
2. videos_match() — frame-set comparison between two videos
3. compute_hashes_for_file() — dispatches image or video hashing by FileType

API surface change note: Plan 03-01's lib.rs calls hash::compute_hashes() directly (takes image bytes). This plan introduces compute_hashes_for_file(path, file_type) which wraps both image and video hashing. Plan 03-04's Task 1 will update lib.rs to use compute_hashes_for_file with FileType routing instead of the direct compute_hashes call. The compute_hashes function is NOT removed — it remains as the core image hashing primitive used by both the Rayon parallel scope (Plan 03-01) and compute_hashes_for_file (Plan 03-04).

1. Add ffmpeg_next import:
   - Add: use ffmpeg_next as ffmpeg;

2. Add compute_hashes_for_video() — extracts frames at 5s intervals:
   - Initialize FFmpeg: ffmpeg::init()
   - Open video path with ffmpeg::media::Input::open_path
   - Get best video stream
   - Create decoder context
   - Compute 5-second frame interval using stream time base
   - Set up scaler: source format -> GRAY8, 32x32, bilinear
   - Iterate packets, decode frames, check PTS against next_frame_pts
   - On matching PTS: scale frame, hash via compute_hashes() (reuse existing DCT-based pHash)
   - Cap at 20 frames per video
   - Fallback (D-07): if no frames extracted, try first frame only
   - Return Vec<[u8; 8; 3]> (one triplet per frame) or Err on failure

3. Add videos_match() — frame-set comparison:
   - Per D-07: N >= 3 matching frames AND >= 50% of analyzed frames match
   - Compare triplets pairwise using triple_match() from Plan 03-01
   - Return bool

4. Add compute_hashes_for_file() — dispatches by FileType:
   - Read file bytes from path, get file size
   - match file_type:
     * FileType::Video: call compute_hashes_for_video(), take median frame's hash, return FileHash
     * FileType::Image: call compute_hashes() with raw bytes, return FileHash
   - This function is the bridge between scan.rs file type info and the correct hashing path

5. IMPORTANT: This plan does NOT modify lib.rs. The scan command's background task in lib.rs (from Plan 03-01) will be updated to call compute_hashes_for_file(path, &file.file_type) in Plan 03-04 (Task 1).
