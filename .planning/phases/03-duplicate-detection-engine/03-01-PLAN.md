   - Import image::{DynamicImage, GenericImageView, imageops}
   - Import image_hash::{ahash, dhash}
   - Implement compute_hashes(image_bytes) -> Result<[u8; 8; 3], String>:

     * Compute aHash via image_hash::ahash
     * Compute dHash via image_hash::dhash
     * Compute pHash via custom compute_phash (DCT-based)
     * Return [ahash, dhash, phash]
   - Implement compute_phash(img: &DynamicImage) -> [u8; 8]:
     * Resize to 32x32 using Lanczos3 filter
     * Convert to grayscale
     * Extract 32x32 pixel values normalized to [-1, 1]
     * Compute 2D DCT-II: D(u,v) = C(u)*C(v) * sum_m sum_n x(m,n) * cos terms
     * Extract 63 low-frequency coefficients (exclude DC at [0][0])
     * Compute median of coefficients
     * Generate 64-bit hash: bit=1 if coeff > median, else 0; set bit 64 from DC
   - Implement hamming_distance(a, b) -> u32: XOR each byte, count_ones
   - Implement triple_match(a1, a2, d1, d2, p1, p2) -> bool: all three distances <= 5 (HASH-05, D-06)

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user → Tauri command (scan_folders) | User-provided folder paths flow into Rust filesystem operations — must be validated |
| user → ScanOptions (min file size) | Numeric input flows into file filtering — must be clamped to non-negative |
| backend → file system | Backend reads all files in user-selected directories — permission boundary |
| Tauri event → frontend | Events emit file paths to the frontend — paths are user-selected, low risk |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | scan_folders folder_paths input | medium | mitigate | Validate each path exists and is a directory (per DF-SCAN-01); skip on error with warning |
| T-03-02 | Tampering | ScanOptions min_file_size_bytes | low | mitigate | Rust u64 type prevents negative values; frontend clamps to >= 0 (DF-INPUT-06) |
| T-03-03 | Information Disclosure | scan:duplicate_found event payload | low | accept | Event emits user-selected file paths only — user initiated the scan |
| T-03-04 | Denial of Service | Large directory trees cause memory pressure | medium | mitigate | walkdir processes entries lazily (iterator); hash_cache is scoped to session (D-08) and dropped on scan complete |
| T-03-05 | Information Exposure | Tauri event path leak in dev tools | low | accept | File paths are visible in Tauri dev console but these are user-selected paths, not sensitive data |
| T-03-06 | Elevation of Privilege | Hidden file skipping misses dotfiles | low | mitigate | Hidden files skipped by convention (file_name.starts_with('.')) — user can explicitly add folders containing dotfiles if needed |
| T-03-SC | Tampering | npm/crates.io package supply chain | high | mitigate | Package legitimacy gate before install — verify image/image-hash/rayon/walkdir from trusted sources |
