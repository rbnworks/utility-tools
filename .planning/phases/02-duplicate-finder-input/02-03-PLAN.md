3. Implement the component:
   a. State:
      - `useState<ScanState>({ viewMode: "input", folders: [], options: { includeSubdirectories: true, includeVideoFiles: true, minFileSizeBytes: 10240 }, scanned: 0, total: 0, completed: false })`

   b. Scan handler (handleScan):
      ```typescript
      const handleScan = useCallback(async () => {
        if (state.folders.length === 0) return;
        
        // Transition to progress view
        setViewMode("progress");
        
        try {
          // Collect folder paths
          const folderPaths = state.folders.map(f => f.path);
          
          // Call Tauri command
          await invoke("scan_folders", {
            folderPaths,
            options: {
              includeSubdirectories: state.options.includeSubdirectories,
              includeVideoFiles: state.options.includeVideoFiles,
              minFileSizeBytes: state.options.minFileSizeBytes,
            },
          });
          setCompleted(true);
        } catch (err) {
          // Set error state — user can retry from input view
          setError(err instanceof Error ? err.message : "Scan failed");
        }
      }, [state.folders, state.options]);
      ```

   c. Progress event listener (useEffect):
      ```typescript
      useEffect(() => {
        if (state.viewMode !== "progress") return;
        
        let unlisten: (() => void) | null = null;
        
        const setupListener = async () => {
          try {
            unlisten = await listen<ScanProgressEvent>("scan:progress", (event) => {
              setScanned(event.payload.scanned);
              setTotal(event.payload.total);
              setCurrentFile(event.payload.file);
            });
          } catch {
            // Event system not available outside Tauri context
          }
        };
        
        setupListener();
        
        return () => {
          if (unlisten) unlisten();
        };
      }, [state.viewMode]);
      ```

   d. New scan handler (handleNewScan):
      ```typescript
      const handleNewScan = useCallback(() => {
        // Reset ALL state
        setFolders([]);
        setOptions({ includeSubdirectories: true, includeVideoFiles: true, minFileSizeBytes: 10240 });
        setViewMode("input");
        setScanned(0);
        setTotal(0);
        setCurrentFile(undefined);
        setError(undefined);
        setCompleted(false);
      }, []);
      ```

          - Loading state: show Loader2 spinner while scanning
          - `onClick={handleScan}`
      - If viewMode === "progress":
        - Render `<ScanProgress>` component with:
          - scanned, total, currentFile, completed, error props
          - onNewScan callback (calls handleNewScan)
      - When completed === true AND viewMode === "progress", ScanProgress shows results-ready state

   f. IMPORTANT — event listener cleanup:

      - Component should NOT crash when run outside Tauri context
