Add Tauri backend dependencies, register plugins, and define the scan command interface.

1. Update src-tauri/Cargo.toml — add plugin dependencies in the [dependencies] section:
   - Add `tauri-plugin-dialog = "2"` (enables native folder picker via rfd)
   - Add `tauri-plugin-fs = "2"` (file system operations; required by dialog plugin per docs.rs)
   - Keep existing: tauri-plugin-log = "2" (unchanged)
   - Follow the existing version convention: `# version` for string-pinned versions (use `"2"` per research)

2. Update src-tauri/src/lib.rs — register plugins and add scan command:
   a. After `.plugin(tauri_plugin_log::Builder::default().build())`, add:
      `.plugin(tauri_plugin_dialog::init())`
      `.plugin(tauri_plugin_fs::init())`
   b. Add the `scan_folders` command to the invoke handler:
      Currently no invoke_handler exists in lib.rs. Add one between the .setup() block and .run():
      ```rust
      .invoke_handler(tauri::generate_handler![scan_folders])
      ```
    c. Add required structs and command function at the top of lib.rs:
       - `ScanOptions` struct with serde Deserialize + rename attributes for camelCase compatibility:
         ```rust
         #[derive(Debug, Deserialize, Clone)]
         pub struct ScanOptions {
             #[serde(rename = "includeSubdirectories")]
             pub include_subdirectories: bool,
             #[serde(rename = "includeVideoFiles")]
             pub include_video_files: bool,
             #[serde(rename = "minFileSizeBytes")]
             pub min_file_size_bytes: u64,
         }
         ```
       - `SessionInfo` struct with serde Serialize:
         ```rust
         #[derive(Debug, Serialize, Clone)]
         pub struct SessionInfo {
             pub session_id: String,
             pub folder_count: usize,
         }
         ```
       - `#[tauri::command]` (fully qualified) async fn scan_folders(app: tauri::AppHandle, folder_paths: Vec<String>, options: ScanOptions) -> Result<SessionInfo, String>`
       - In the command: validate each path exists and is a directory using std::fs::metadata()
       - Return SessionInfo with a new uuid (use uuid::Uuid::new_v4() — must add uuid = "1" to Cargo.toml deps)
   d. IMPORTANT: The existing .setup() closure must be preserved. Plugins are added via .plugin() calls, NOT inside .setup().

3. Update src-tauri/capabilities/default.json:
   - Add "dialog:default" to the permissions array:
     `"permissions": ["core:default", "dialog:default"]`
   - This grants the dialog plugin its required permissions for the picker to work at runtime

4. Add uuid dependency to Cargo.toml:
   - Add `uuid = { version = "1", features = ["v4"] }` to [dependencies]

5. Verify Rust compiles:
   - Run `cd src-tauri && cargo check` from project root
   - Must pass with zero errors (warnings are OK — e.g., unused imports from ScanOptions)
   - This confirms the plugin registrations, command definition, and capability config are all correct

NOTE: The scan command in this phase only validates paths and returns a session ID. Actual scanning (Phase 3) will use this session and emit progress events.
